# Home artwork provenance

Source: the user-selected MarineCast home reference (1536 × 1024), supplied for this application design. The original remains unchanged and is retained privately; it is not redistributed in this branch.

`marinecast-coastal-map.jpg` is an Image Gen edit of that reference with only editable branding/navigation removed. The geographic labels belong to the illustration. It is illustrative marketing artwork and must never be treated as scientific or navigational cartography. The generated original is retained privately; the application asset is JPEG encoded for delivery.

`marinecast-wave.png` is an Image Gen extraction of the supplied wave mark, reduced to 256 × 128 with transparent alpha. The generated original is retained privately; this PNG is the application delivery asset.

The wordmark is editable HTML using self-hosted [Barlow Condensed](https://fonts.google.com/specimen/Barlow+Condensed), weight 600. The font is distributed under the adjacent `OFL.txt`, copied from the official Google Fonts repository. Navigation symbols use the existing Lucide icon library.
